# Teriash Addons — GitHub Pages

Statyczna, responsywna strona projektu Teriash Addons. Bez kompilacji, frameworków i serwera.

## Publikacja w obecnym repozytorium

1. W repozytorium `Teriash/teriash-addons` utwórz folder `docs`.
2. Przenieś **zawartość** tego ZIP-a (pliki `index.html`, `style.css`, `script.js`, `favicon.svg`, `.nojekyll`) do `docs/` (README może również tam pozostać).
3. W GitHub przejdź do **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Wybierz **main**, katalog **/docs**, następnie **Save**.
5. Strona będzie dostępna pod `https://teriash.github.io/teriash-addons/` (jeśli login GitHub to `Teriash`).

**Ważne:** nie zastępuj plików skryptu w katalogu głównym repozytorium. Strona jest osobną częścią projektu w `docs/`.

## Edycja

- `index.html` — teksty, sekcje, adresy URL.
- `style.css` — kolory i wygląd.
- `script.js` — mobilne menu i rok w stopce.
- `favicon.svg` — ikona strony.

Przycisk instalacji prowadzi do istniejącego skryptu `https://raw.githubusercontent.com/Teriash/teriash-addons/main/teriash-addons.user.js`.
